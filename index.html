REGINA Backup

REGINA Backup is a privately operated backup utility used to securely store encrypted application backups in the owner's Google Drive account.

How it works

The application uses Google OAuth 2.0 to authorize access to Google Drive. Backup files are encrypted locally before being uploaded.

Data access

REGINA Backup requests the Google Drive drive.file permission to manage files created or accessed through the application.

Privacy

For information about data handling, see our Privacy Policy.

This utility is intended for private use and is not offered as a public backup service.
