Privacy Policy

Last updated: November 8, 2026

Purpose

REGINA Backup is a private utility for creating encrypted backups and storing them in the application owner's Google Drive account.

Google Drive Access

REGINA Backup uses the Google Drive API with the drive.file permission to create and manage application-accessible backup files.

Data Processing

Backup data is encrypted locally before upload. The application does not operate a separate public server for collecting user data.

Data Sharing

REGINA Backup does not sell personal information or intentionally share backup contents with third-party advertisers.

Storage and Deletion

Encrypted backup files are stored in the authorized Google Drive account. The account owner controls access to and deletion of these files.

Contact

Questions about this private application can be directed to the support email displayed on its Google OAuth consent screen.
